# Arus — Front-end SOT Starter

Prototype front-end Sistem Informasi Pengelolaan Transaksi Distributor Layanan Digital.

## Teknologi
- React 18
- Vite 6
- TailwindCSS 3
- lucide-react

## Menjalankan project
Pastikan Node.js LTS dan npm sudah terpasang.

```bash
npm install
npm run dev
```

Buka URL lokal yang ditampilkan Vite (umumnya `http://localhost:5173`).

Build:
```bash
npm run build
```
